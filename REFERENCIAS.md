# Referencias bibliográficas verificadas

Fecha de consulta: 17 de octubre de 2026. Se verificaron metadatos y resúmenes públicos; no se afirma lectura de texto completo donde el editor restringió el acceso.

1. Persico V, Pescapé A, Picariello A, Sperlí G. Benchmarking big data architectures for social networks data processing using public cloud platforms. Future Generation Computer Systems. 2018;89:98–109. https://doi.org/10.1016/j.future.2018.05.068
   - ScienceDirect: https://www.sciencedirect.com/science/article/abs/pii/S0167739X17328303
   - Registro institucional de los autores: https://www.iris.unina.it/handle/11588/720068
   - Aporte: respalda comparar Lambda y Kappa mediante una carga y un entorno explícitos. Su resultado en redes sociales/Azure no se traslada automáticamente a este laboratorio.
2. Lawi A, Panggabean BLE, Yoshida T. Evaluating GraphQL and REST API Services Performance in a Massive and Intensive Accessible Information System. Computers. 2021;10(11):138. https://doi.org/10.3390/computers10110138
   - Registro institucional: https://scholar.unhas.ac.id/en/publications/evaluating-graphql-and-rest-api-services-performance-in-a-massive/
   - El registro institucional enlaza la publicación Scopus 85119061756: https://www.scopus.com/pages/publications/85119061756
   - Aporte: respalda medir respuesta, throughput, CPU y memoria en una comparación de API. No se copian sus porcentajes como resultados propios.

ScienceDirect es una plataforma editorial; Scopus es una base de indexación. Las referencias se citan por autores, artículo y DOI, no como si “Scopus” fuese el autor. El vínculo de indexación del artículo 2 fue verificado en el registro institucional; el acceso completo a Scopus puede exigir suscripción.
